# 🐾 Nhật Ký Của Sóppi (@soppipeo2k2)

> Trang web nhật ký cá nhân cực kỳ dễ thương, vui nhộn và bắt mắt kể về cuộc sống hằng ngày của chú cún cưng mũm mĩm tên là **Sóppi**.

---

## 📸 Giao diện ứng dụng
*(Chừa sẵn chỗ để bạn chèn ảnh chụp màn hình trang web sau khi chạy thực tế)*
![Ảnh chụp giao diện dự án](https://placeholder.com)

## 📌 Tính năng nổi bật

* **Thông tin nhân vật**: Hiển thị hồ sơ cá nhân của Sóppi (Bé trai, sinh năm 2k22, nặng 14.5kg, dài 74cm và chuyên trị áo Size 5XL).
* **Dòng thời gian "Một ngày của Sóppi"**: Kể lại lịch trình 4 buổi (Sáng, Trưa, Chiều, Tối) bằng giao diện Timeline sinh động dưới góc nhìn hài hước.
* **Sổ nhật ký tương tác**: Cho phép chủ nhân tự gõ thêm câu chuyện mới, chọn ngày/giờ, biểu cảm và lưu hiển thị ngay lập tức (Dữ liệu được lưu trữ bền vững qua `localStorage`).
* **Hiệu ứng lung linh**: Các icon dấu chân, xương, trái tim và hạt kim tuyến lấp lánh rơi nhẹ trên màn hình.
* **Âm thanh vui nhộn**: Tích hợp trình phát nhạc nền tự động tạo giai điệu vui tươi độc lập bằng Web Audio API, có nút Bật/Tắt tiện lợi.

## 🛠️ Công nghệ sử dụng

* **Frontend**: HTML5, CSS3 (Flexbox, CSS Grid, Keyframes Animation), JavaScript thuần (Vanilla JS)
* **Fonts**: Google Fonts (`Nunito` tròn trịa, hỗ trợ tiếng Việt hoàn hảo)
* **Storage**: Browser `localStorage` để lưu trữ nhật ký tự viết

## 🚀 Hướng dẫn chạy dự án

Bạn không cần cài đặt các gói phụ thuộc phức tạp, chỉ cần thực hiện 2 bước đơn giản sau:

1. **Tải mã nguồn về máy** (hoặc copy toàn bộ code file HTML).
2. **Double-click trực tiếp vào file HTML** (ví dụ: `index.html`) để mở và trải nghiệm ngay trên trình duyệt web của bạn.

> 💡 **Mẹo nhỏ:** Để đổi ảnh đại diện của Sóppi, bạn hãy mở file code ra, tìm đến thẻ `<img>` ở phần `<header>` và thay thế đường dẫn `src` bằng liên kết hình ảnh Sóppi của bạn hoặc đường dẫn file ảnh nằm cùng thư mục nhé!
